# Fixed sensing application protocol

This is the requested unversioned 15x13 format. It is incompatible with the earlier experimental eight-byte-metadata/fallback format and with the 30x15 codec. Configure the receiver explicitly for this protocol; there is no in-packet version or raw-mode bit. The current 5+3 date/battery packing supersedes the earlier 4+4 packing, so both endpoints must change together; old packets cannot be identified automatically.

```text
byte 0:       [unsigned node ID:8]
byte 1:       [unsigned date code:5][unsigned battery code:3]
bytes 2..5:   [IEEE754 float32 scale:32, network/big-endian]
byte 6:       [schedule:3][Q[0,0] bits 7..3:5]
byte 7:       [Q[0,0] bits 2..0:3][Q[0,1] bits 7..3:5]
...           remaining first-frame coefficients, then 182 Rice symbols
last byte:    final symbol bits followed only by zero terminal padding
```

All eight schedules are hard-coded in `src/payload.cpp` and `host/decoder.py` in the exact order requested. For each schedule, the encoder computes `B_rice = sum((u >> k[c])+1+k[c])` over t=1..14, c=0..12. Differences are `int16(Q[t,c])-int16(Q[t-1,c])`; ZigZag is `2*d` for d>=0, otherwise `-2*d-1`. Symbols are time-major. Unary quotient is q zeros then one, followed by k remainder bits MSB-first. First frame consists of all 13 exact two-complement int8 bytes. No extra alignment exists inside this stream.

The selected bank entry minimizes final packed bytes, then total bits, then index. Because the header/index/first-frame costs are identical for all entries, minimizing exact bit count implements that same ordering. Only the three-bit index is sent. The scale used for quantization is the actual stored float32 value. Quantization rounds ties to even, including negative halfway values, and clips to [-127,127]. The scale is 1 for an all-zero floating feature matrix. A silent waveform normally has a nonzero MFCC coefficient 0; it is still encoded.

Application length is exactly `6 + ceil((3 + 104 + B_rice)/8)`. There is no raw fallback or fragmentation. The library limit is 255 application bytes; an oversize packet returns an error with its exact required length before any output or RF send. The alternating-all-columns ±127 test requires 5,947 bytes and is explicitly rejected. Lower radio/regional payload limits, if applicable to the selected deployment, need separate configuration/validation; 255 is not a universal legal LoRa payload allowance. Radio explicit-header/CRC/PHY overhead is not part of these application bytes.

Node ID, date code and battery code are unsigned caller-supplied integers, with wire ranges 0..255, 0..31 and 0..7 respectively. Byte 1 is `(date << 3) | battery`; decoding uses `byte1 >> 3` and `byte1 & 7`. Date and battery meanings remain opaque; no calendar, voltage or percentage mapping is assigned. The first six bytes contain no path or SNR. A receiver knows the fixed matrix shape and parses exactly 182 deltas, verifies int8 reconstruction and positive finite scale, then accepts fewer than eight remaining bits only when all are zero. It rejects truncation, invalid/unbounded unary syntax, impossible values and extra bytes. Valid codeword corruption cannot always be detected by syntax; PHY CRC remains important.

## Completely decoded real code-generated example

The matrix and scale come from the existing dataset row below. Node 42, date code 11 and battery code 7 are **synthetic host test inputs**, not actual node telemetry. These bytes were generated by the firmware's C++ encoder and independently decoded in Python; they were not received over RF.

Source path: `field/field/test/difficult_cases/F_20200218001001_19_T8.6.wav`.

```text
2a5f3fee2038703fffa01fa01fdfe00000000012d7a6e59332f63dbceeff7bfbce44f2f52b2cf3b6a24f999cdcc8c6d8a7289556f212922c2e80c284249d606088510af4
```

The six fixed header bytes are `2a 5f 3f ee 20 38`: node=42, date-code=11, battery-code=7, scale=1.8603582382202148 (binary32 bits `3fee2038`). Byte 6 is `70` = `011 10000`: schedule `011` = 3, then the first five bits of Q[0,0]=-127 (`10000001`).

The complete payload is 68 bytes. Rice symbols use 387 bits; the data segment is 3+104+387=494 bits, with 2 zero padding bits. Thus 6+ceil(494/8)=68 bytes.

All 15 time-major rows, each with 13 signed coefficients:

An approximate floating feature matrix is recovered as `Q.astype(float32) * float32(scale)`. The signed integer matrix and scale bits themselves are recovered exactly. The matching machine-readable example is `results/example_payload.json`; `results/example_payload.bin` is the binary packet.

```bash
python sensing/host/decoder.py --file sensing/results/example_payload.bin
```
